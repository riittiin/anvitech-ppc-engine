Optimize plan — tries many different job sequences on the current order book and keeps the best plan found (smaller delivery gaps first, fewer total days second). Same machines, same people — only the order in which jobs claim the machines changes. Committed / urgent orders are never moved. Optimizing finds the best job order globally, so it supersedes the “Expedite” tick (which only nudges order locally) — an applied optimized plan runs with Expedite set aside.
This runs on the server — you can leave this tab open and it keeps going. Watch “best so far” improve and press Stop & keep best whenever you’re happy; most of the gain comes in the first ~150 plans.
