Scheduling

Order batching (how far apart two same-item orders can be to run together) is chosen automatically by the engine — you don't set it.

Minutes added before each CNC/VMC job starts, to account for machine changeover.

Overlap between steps (tuned automatically by Optimize — you don't set this; currently 50%): how much of a job's next step can start before the previous step is completely finished. Higher overlap finishes orders sooner but runs two of that order's processes at the same time.

Machine set (tuned by Optimize — you don't set this): Allotted only. Whether the optimizer may also use each step's Suggested machines to balance load off a busy machine.

Order priority

The order in which jobs are scheduled is decided automatically by the engine (most-urgent-first, tuned by Optimize) — you don't set it.

Options

When a job step can run on more than one machine, share the work across them so it finishes sooner. Turn off to always keep a batch on one machine.

    Efficiency report

    Per-operator output vs standard for a month (pure reporting: never changes the plan).

    Attended (min) = time on shift minus recorded downtime and setup. Earned (min) = standard time credited for GOOD pieces only — rejects earn nothing. Efficiency % = Earned ÷ Attended × 100. Pace vs standard (x) = how many times faster/slower than standard cycle time (1.0 = exactly standard, 1.2 = 20% faster). Reject % = rejected ÷ (good + rejected) qty. No-standard punches = entries for an item/process with no time standard on file — excluded from both earned and attended time, so they never count against the operator.
